# Architecture

## Target shape

Browser / PWA → Next.js UI → Supabase Auth/RPC → PostgreSQL academic engine.

The browser is never authoritative for mastery, XP, coins, rank, school membership or academic progress.

## Current stabilization boundary

Phase A–C intentionally provides only a clean StudentApp shell. Academic modules remain disabled until staging Supabase, Auth, RLS and RPC tests are validated.

## Repository lineage

This repository consolidates the project name `ens-sonson-app` while preserving the pre-existing static implementation on `legacy/static-20260819`. The new Next.js baseline is a controlled reconstruction, not the original 2026-08-15 source tree.
